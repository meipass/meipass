## Projects

### [MarketPlace-RestAPI](https://github.com/meipass/MarketPlace-RestAPI)

REST API for a marketplace built with Node.js, TypeScript, Express 5 and PostgreSQL

- User registration and JWT authentication
- Access and refresh tokens, including refresh-token rotation
- Product CRUD with ownership checks
- Search, filtering, sorting and pagination
- Password hashing, input validation and centralized error handling

**Stack:** Node.js, TypeScript, Express, PostgreSQL, `pg`, `jsonwebtoken`, `bcrypt`
